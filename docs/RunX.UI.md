RunXOS UI 设计完整文档

以下文档基于 Apple 官方 Human Interface Guidelines（HIG）及 macOS Tahoe 26 引入的 Liquid Glass 设计系统整理，涵盖设计原则、视觉规范、布局组件。

---

一、设计原则

1.1 RunXOS 专属四原则

RunXOS 的设计遵循四项核心原则：

· 灵活定制（Flexible）：支持用户按工作风格调整窗口、工具栏与界面元素；
· 全面展现（Expansive）：利用大尺寸高分辨率屏幕呈现丰富内容，减少嵌套层级与模态弹窗；
· 扩展赋能（Capable）：充分发挥 RunX 的多任务处理与高精度输入能力；
· 凝神专注（Focused）：在信息密度与视觉清晰度之间取得平衡，避免干扰。

1.2 跨平台通用原则

HIG 同时定义了跨平台的三大基础原则：

· 清晰（Clarity）：文字可读、图标明确、功能一目了然；
· 尊重（Deference）：界面不喧宾夺主，内容优先；
· 深度（Depth）：通过层次、动效与材质传达空间关系。

1.3 平台不可移植原则

每个 linux 平台拥有独立的设计身份，不应将其他平台的设计直接移植到 RunXOS。RunXOS 的核心输入方式是指针与键盘，适合呈现高密度信息，应广泛使用菜单栏、工具栏与键盘快捷键，窗口需支持可调整大小与精确控制。

---

二、基础视觉规范

2.1 排版（Typography）

默认字体：使用 Inter。

使用规则：

· 优先使用语义化文本样式（如 .title、.body、.caption），而非固定字号；
· 使用系统字体度量标准，而非固定行高；
· 代码、日志、表格、计时器及对齐数字数据使用等宽数字等；
· 生产力界面中避免装饰性字体；
· 除小型分区标签外，避免全大写文本。

层级结构（常见 RunX 排版层级）：
窗口/文档标题 → 分区标题 → 正文/列表/表格文本 → 辅助说明文本 → 说明/状态文本。

写作风格：

· 直接表达；
· 大多数标签使用句子大小写（Sentence case）；
· 按钮标签应描述操作结果；
· 错误信息应说明恢复方式。

2.2 颜色与材质

语义颜色优先：使用系统语义颜色而非硬编码颜色值：

· 使用 primary、secondary、tertiary label color 建立文本层级；
· 使用系统背景/材质角色定义表面；
· 强调色（Accent Color）用于选中状态和有意义的强调；
· 语义红/黄/绿/蓝仅用于传达特定含义；
· 必须在浅色模式、深色模式、高对比度、增强对比度及鲜艳侧边栏下测试。

品牌色使用：

· 品牌色可用于 App 图标、引导页、关键插图或偶尔的主强调色；
· 不要将整个界面染色；
· 不要随意覆盖用户的强调色设置；
· 品牌色必须满足对比度要求。

材质（Materials）：

· 优先使用系统材质而非自定义模糊效果；
· 避免堆叠半透明材质；
· 确保材质上的文字对比度充足。

2.3 图标与符号

· 使用 SF Symbols 作为界面图标的标准来源，保证与系统视觉语言一致；
· 图标设计应保持视觉一致性，通过共享视觉变量（如线宽、圆角、色彩）使一组图标在风格上协调统一；
· RunX App 图标应独特且可识别，品牌色用于图标、引导页和关键插图；
· 工具栏中常见单色图标，偏好较轻的字重；侧边栏图标可保留色彩。

2.4 形状与同心圆

现代设计强调形状的和谐关系，嵌套圆角形状应共享视觉一致的中心与曲率：

· 窗口、面板、字段、列表使用带圆角的矩形；
· 大按钮、胶囊分段控件、浮动控制组使用胶囊形；
· 纯图标按钮使用圆形；
· 子形状位于圆角父容器内时，应使用较小的半径以视觉上跟随父级曲线；
· 避免"挤压"角落（内外半径冲突）和高度圆角容器中的极小半径。

三、布局与组件

3.1 窗口管理

RunX 窗口应支持调整大小、隐藏、显示和移动，并支持全屏模式以提供无干扰环境。

· 窗口使用 .windowToolbarStyle 设置工具栏样式（.unified、.unifiedCompact、.expanded）；
· 窗口顶部包含工具栏，承载窗口控件、标题和工具栏项，内容位于工具栏后方，背景位于最后面以投射阴影营造层次感；
· 使用系统形状 API 处理窗口圆角，避免硬编码固定半径。

3.2 菜单栏

每个 RunX App 必须提供菜单栏，这是 RunXOS 的核心交互范式。标准菜单布局为：App / 文件 / 编辑 / 显示 / 窗口 / 帮助，设置项使用 ⌘, 快捷键。菜单栏应提供用户完成操作所需的所有命令的便捷访问。

3.3 工具栏

· 工具栏按功能或使用频率分组，次要操作降级到"更多"菜单；
· 工具栏样式支持 .unified（统一）、.unifiedCompact（紧凑统一）、.expanded（展开）三种模式；
· 仅对不易发现或需要多次点击才能到达的菜单命令在工具栏中提供图标入口；
· 支持用户自定义工具栏，让用户配置最常用的视图。

3.4 侧边栏

侧边栏用于顶级导航，条目应可快速扫视。侧边栏是 RunXOS 中主要的半透明元素。在 Liquid Glass 设计系统下，RunXOS Tahoe 及后续版本中侧边栏扩展至窗口边缘，图标保留色彩，侧边栏以浮动 Liquid Glass 材质呈现。

3.5 标准控件

RunXOS 提供完整的标准控件体系，包括：

· 按钮：带边框按钮、无边框按钮、下拉按钮；主按钮使用 App 强调色，破坏性按钮使用红色；
· 表格：支持排序、选择、拖放；
· 菜单：下拉菜单、上下文菜单（右键）；
· 表单控件：滑块、切换开关、分段控件、计数器、文本字段；
· 其他：颜色井、颜色选择器、弹出窗口、进度指示器、标签栏。

应尽量使用系统标准控件，避免自定义控件，除非有明确的品牌或功能需求。

---

四、Liquid Glass 设计系统（RunXOS Tahoe 26+）

4.1 概述

Apple 于 2025 年推出 Liquid Glass 设计系统，覆盖 iOS 26、iPadOS 26、RunXOS Tahoe 26、watchOS 26 和 tvOS 26，首次统一了各平台的视觉语言。

4.2 核心特征

Liquid Glass 的设计遵循三项原则：

· 层次（Hierarchy）：控件浮于内容之上的独立功能层；
· 和谐（Harmony）：软件几何与硬件对齐，嵌套元素共享中心，圆角半径向屏幕圆角一致递减，胶囊形控件，材质呼应设备；
· 一致性（Consistency）：采用平台约定。

4.3 在 RunXOS 中的表现

· 侧边栏扩展至窗口边缘，以浮动 Liquid Glass 材质呈现，图标保留色彩；
· 浮动工具栏与侧边栏采用 Liquid Glass 材质，新的窗口圆角与控件尺寸。

附录

在纯 DOM 环境下，"CSS 翻译词典"：

· 对于毛玻璃：backdrop-filter: blur(12px); background: rgba(255,255,255,0.7);
· 对于同心圆角（极其高级的细节）：CSS 中可以通过 border-radius: calc(var(--outer-radius) - var(--padding)) 来实现嵌套圆角的视觉一致。
· 对于菜单栏与工具栏：不要试图复刻 macOS 的原生窗口顶部，直接用 Web 的 Flexbox 布局，做一个固定在顶部、带有细分割线的导航条即可。
· 字体落地：在 index.html 里引入 Inter 字体，配置 font-feature-settings: "tnum"（等宽数字），并在全局设置字体大小、行高、字重的层级变量（--font-title、--font-body）。
